# FlowGenie 2차 수정 계획 (2026-06-19)

> 진단: [현재-진단.md](현재-진단.md)
> 목표: Google Flow **대화형(Gemini agent) 패널**에서도 안정적으로 제출·완료감지가
> 되도록 실제 실행 경로(CDP 모드)를 보완하고, 실패 시 자가진단으로 selector를 정밀화한다.

## 적용한 수정 (이번 차수에서 반영 완료)

### A. 제출 견고화 — `background/service-worker.js` `runDomModeCDP`
- **Enter 우선 제출**: 텍스트 삽입(`cdpInsertText`) 직후 CDP `Input.dispatchKeyEvent`로
  Enter(keyDown→char→keyUp) 전송. 채팅 컴포저는 Enter 제출이 가장 확실.
  - 신규 헬퍼: `cdpPressEnter(tabId)`, `readEditorText(tabId)`.
- **제출 검증**: 제출 후 에디터 `textContent`가 비었는지 확인. 비었으면 성공.
- **버튼 fallback 개선**: 미제출 시 컴포저 바(form/부모) 안에서 **가장 오른쪽 아이콘 버튼**
  (전송 화살표)을 골라 클릭. `button:not([disabled])` 조건. 그래도 안 되면 Enter 1회 재시도.
  최종 미제출이면 "Prompt not submitted" 에러로 명확히 구분.

### B. 완료감지 완화·정착 — `runDomModeCDP` Step 7 주입 함수
- **1장 이상이면 성공**: 첫 신규 이미지 발견 후 **정착(settle) 8초** 동안 추가 수집 →
  `expectedCount` 도달 또는 정착 시 resolve. 0장일 때만 timeout까지 대기.
- 반환부: `imageUrls.length >= 1`이면 다운로드하고 COMPLETE (1~4장 모두 허용).
- timeout은 `TIMING.GENERATION_TIMEOUT_MS`(120s)로 통일.

### C. 실패 시 DOM 자가진단 — `dumpFlowDiagnostics(tabId, reason)`
- 제출 실패 / 0장 실패 시 호출. 컴포저 하단 버튼들의 aria-label·좌표·아이콘 여부,
  이미지 URL 패턴 분포, agent 텍스트 힌트, 에디터 텍스트를 console.warn + 에러 메시지에 포함.
- → 다음 실행 로그/CSV에서 **정확한 전송 버튼·이미지 URL 패턴**을 확정해 selector 정밀화.

### D. selector 중앙화 — `automation/selectors.js`
- `SLATE_EDITOR`, `COMPOSER_BAR`, `SEND_BUTTON` 추가, `RESULT_CONTAINER`에 media-grid/gallery
  후보 추가. 대화형 모드 관련 주석 명시. (CDP 주입 함수는 자체 동작, 유지보수 기준 일원화.)

### E. 모델 주석 — `shared/constants.js`
- MODELS 주석에 "실 UI = Nano Banana 2(대화형), 코드가 모델 선택 안 함" 명시.

## 변경 파일
- `background/service-worker.js` (A·B·C)
- `automation/selectors.js` (D)
- `shared/constants.js` (E, 주석)
- `_context/현재-진단.md`, `_context/260619-2차-수정계획.md` (신규)

## 검증 절차
1. `chrome://extensions` → FlowGenie **Reload**.
2. labs.google Flow 프로젝트 열고 사이드패널 **Connected** 확인.
3. `_context/ch05_script.json` Load JSON → Queue 20.
4. **Start** 후 관찰:
   - 프롬프트가 채팅창에 들어간 뒤 **즉시 제출(Enter)** 되는가 (입력창이 비워지는가).
   - 신규 이미지 1~4장 뜨면 **초록(COMPLETE)** 전환되는가.
   - 실패 시 사이드패널 alert / CSV `error` 열에 `[diag:...]` 진단 문자열이 남는가.
5. 목표: 빨강 13/20 → **대폭 감소**(이상적으로 0~소수).
6. 회귀: Stop 즉시 중단, ETA/카운터 정상, `다운로드/FlowGenie/ch02_xx_*.png` 생성 확인.

## 후속 (3차 후보)
- 진단 덤프로 확정된 selector를 `SEND_BUTTON`/`RESULT_CONTAINER`에 하드코딩해 휴리스틱 의존 축소.
- 이미지 검출을 **최신 assistant turn 컨테이너로 스코프**해 누적 대화 오염 제거.
- 모델 선택(Nano Banana 2 등) UI 자동화 추가.
- 실패 자동 재시도(`TIMING.RETRY_MAX`) 연결.
