# FlowGenie 현재 진단 (2026-06-19)

## 증상
- `ch05_script.json`(20 scenes, "배움")로 배치 실행 → **20개 중 성공 7 / 실패 13(빨강)**.
- 화면 **가운데에 대화형 패널**이 생김:
  - 제목 "Early 2000s Media Port…"
  - Gemini 응답 "I'm going to generate 4 images of the programmer… using the Nano Banana 2 model"
  - 하단 채팅 입력창 "무엇을 만들고 싶으신가요?"

## 원인: Google Flow UI가 대화형(에이전트) 모드로 변경됨
가운데 창은 **Google Flow의 대화형(Gemini agent) 패널**이다. 과거의 "프롬프트 → 즉시 생성"
구조가 아니라, 입력창이 **채팅 컴포저**가 되었고 Gemini가 대화로 이미지를 생성한다.
프롬프트 입력창(Slate 에디터)은 동일한 `[data-slate-editor="true"]`라서 FlowGenie가
이 채팅창에 프롬프트를 넣고 있다.

## 실제 실행 경로
- 실제로 동작하는 코드는 `background/service-worker.js`의 **`runDomModeCDP`** (CDP 모드).
- `automation/dom-mode.js`는 **현재 호출되지 않는 레거시 경로**. 두 경로의 동작이 어긋나 있음
  (dom-mode.js는 Enter+클릭 둘 다 하지만, 실제 쓰이는 CDP 경로는 클릭만 했음).

## 핵심 인과 사슬
**결함1·2 (미제출) → 신규 이미지 0장 → 결함3 (0장 = FAILED) → 빨강 13건.**
성공한 7건은 버튼이 우연히 맞은(또는 제출이 우연히 된) 경우로 추정.

## 미해결/후속 확인 필요
- 대화형 컴포저의 **정확한 전송 버튼 selector / 결과 그리드 컨테이너 selector**는
  라이브 DOM 캡처로 확정하는 것이 가장 확실. → 2차 수정에 **실패 시 DOM 자가진단 덤프**를
  넣어 다음 실행 로그로 정밀화한다.
- Enter가 "줄바꿈"이 아니라 "제출"로 동작하는지 → 제출 후 에디터가 비워졌는지로 검증.
